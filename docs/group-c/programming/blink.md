# Маячок

Первая программа: заставим светодиод мигать раз в секунду.

## Что понадобится

- Arduino Uno;
- светодиод;
- резистор 220 Ом;
- макетная плата и провода.

Схему подключения и расчёт резистора смотрите в теме [Светодиод и резистор](../theory/led-resistor.md).

## Скетч

```cpp title="blink.ino" linenums="1"
const int LED_PIN = 13;   // (1)!

void setup() {            // (2)!
  pinMode(LED_PIN, OUTPUT);
}

void loop() {             // (3)!
  digitalWrite(LED_PIN, HIGH);  // (4)!
  delay(1000);                  // (5)!
  digitalWrite(LED_PIN, LOW);
  delay(1000);
}
```

1. Номер пина записываем в константу: если захотим перенести светодиод на другой пин, исправим только одну строку.
2. `setup()` выполняется один раз при включении платы. Здесь настраиваем пин как **выход**.
3. `loop()` повторяется бесконечно, пока на плату подаётся питание.
4. `HIGH` подаёт на пин 5 В, и светодиод загорается.
5. Пауза в миллисекундах: 1000 мс = 1 секунда.

## Как это работает

Программа включает светодиод, ждёт секунду, выключает его и снова ждёт секунду. Затем `loop()` начинается заново, и получается мигание.

!!! tip "Встроенный светодиод"
    На Arduino Uno к пину 13 уже подключён светодиод **L** на самой плате, поэтому скетч можно проверить вообще без схемы.

## Задания

1. Сделайте так, чтобы светодиод мигал в два раза быстрее.
2. Сделайте «маячок»: короткая вспышка 100 мс, затем пауза 900 мс.
3. Подключите второй светодиод и заставьте светодиоды мигать по очереди.
