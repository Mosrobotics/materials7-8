# Полезные ссылки

## RoboCup
- [Робокап в России](https://robocuprussiaopen.ru) — Российский оргкомитет. Новости, регламенты на Русском.
- [RoboCup Junior](https://junior.robocup.org) — Глобальный сайт. Актуальные регламенты и новости.

## Справочники

- [Вики Амперки](https://wiki.amperka.ru/) — конспекты, схемы и уроки по Arduino на русском.
- [Справочник языка Arduino](https://docs.arduino.cc/language-reference/) — все функции с примерами (англ.).

## Симуляторы

- [Wokwi](https://wokwi.com/) — симулятор Arduino в браузере, без регистрации.
- [Tinkercad Circuits](https://www.tinkercad.com/circuits) — сборка схем и программирование блоками.

## Программы

- [Arduino IDE](https://www.arduino.cc/en/software) — среда для написания и загрузки скетчей.
- [VS Code](https://code.visualstudio.com/download) - среда для разработки с расширенными возможностям.
- [Orca](https://www.orcaslicer.com) - cлайсер для подготовки к печати.
